# 画面与图标

五张场景和三张人物图集使用图像生成工具绘制。程序将它们嵌入可执行文件，离线即可显示。每张人物图集包含两种姿势，一侧站立、手边拿合起的书，另一侧坐下、捧着打开的书。

- **场景**　[树下](../assets/tree.png) · [湖边](../assets/lake.png) · [江南庭院](../assets/garden.png) · [紫禁城](../assets/forbidden-city.png) · [喜马拉雅山](../assets/himalaya.png)
- **人物**　[猪猪侠](../assets/gg-bond.png) · [慢羊羊](../assets/slow-goat.png) · [橙留香](../assets/orange-hero-v16.png)

人物可以与任一场景组合。动画人物分别来源于《猪猪侠》《喜羊羊与灰太狼》和《果宝特攻》，图集中采用了为本程序重新绘制的形象。[素材与授权说明](../NOTICE.md)

应用图标取意于时间与起身。长短表针分出三个山形，上升箭头和右下方的断弧呼应艮卦。图标由程序中的绘图代码生成。[图标源文件](../AppMark.cs)
